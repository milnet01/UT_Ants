# UTA-0263 spec 4.1: which FireTextures are flames, labelled by hand.
#
# One line per FireTexture a map in the reference install draws on a BSP
# surface, matched within the map and the packages it imports:
#   <package> <texture> flame|other
# Labelled from the name and the bake's still picture, and for the unclear
# ones from how maps use the texture. A flame is fire as a player would
# call it: torches, braziers, burning urns, whatever colour. Lava, smoke,
# shields, energy, lightning effects, waterfalls and sparkles are other.
# lightning6 is a flame despite its name: burning sparks, rising, a blue
# flame shape on torch sheets. ancsconc and offred use spark types the
# still does not model; ancsconc is an orange sconce in the fire package,
# offred is blue sphere lightning.
# Package and texture names compare case-insensitively.
