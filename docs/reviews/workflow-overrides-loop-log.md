## Retired 2026-09-08

**The document this log records was deleted on the user's decision, at the
close of the loop-3 gate above.** The rows stay: they are why.

The gate's own verdict was that a violent cap on a small document meant a
contract never settled, and it was right in a way the run could not fix from
inside the document. The file's only surviving content was a ceiling
`workflow.md` § 1 does not impose — **stricter than the global rule rather
than a departure from it**, so a deltas-only override file was the wrong shape
for it from the moment § 1 changed on 2026-09-07. Everything else it held was
a second copy of `CLAUDE.md` § Running two sessions at once, and every loop of
this gate found that copy saying something its original does not.

**The ceiling now lives in `CLAUDE.md` § Running two sessions at once**, which
every session loads at start-up, where this file was read only by someone who
went looking. That section is now marked as the single home for those rules.

**`docs/standards/README.md` keeps the clause naming `workflow.md` as a thing
a project may override.** It is still true: `CLAUDE.md` § Overrides routes any
future `workflow.md` departure to `docs/standards/`, and the sibling
`versioning-overrides.md` still lives there. Reverting it would restore the
contradiction loop 3 found.

**What this log does not record, because the run could not settle it:** whether
`CLAUDE.md` rule 3's start-up test detects a third session at all. `ListAgents`
was measured machine-wide during loop 3 and does not scope to a project. That
is filed as its own roadmap item rather than answered here.
