What I want this project to be is a remake of the UT99 / UT GOTY game with some more modernised graphics (doesn't need ray tracing) like dynamic lights / shadows.  It must play the same as
the original though and must be able to play those same old maps while modernising the visuals.  I don't require single player but I want the Monster Hunt World game and death match as well
as team death match.  It should also allow in game chat like the current game, offer flash lights for darker areas, have a map editor to create new maps and inbetween maps on the Monster
Hunt World it should offer a map browser and allow people to vote for the next map (however, the map names should be friendlier than the current game).

The PvP games should offer mutators like the current game and the same for Monster Hunt World along with all the other usual bells and whistles.
